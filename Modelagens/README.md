# 🧱 Modelagens Simples 

Esta pasta reúne exemplos de **modelagens de banco de dados relacionais simples**, desenvolvidas com foco em **normalização até a Terceira Forma Normal (3FN)**.

Cada modelagem parte de um cenário real ou hipotético, sendo estruturada da seguinte forma:

- ✅ **Modelo Conceitual (MER)** – utilizando o Modelo Entidade-Relacionamento para representar entidades, atributos e relacionamentos.
- 🔄 **Modelo Lógico Relacional** – com as entidades transformadas em tabelas.
- 🧹 **Aplicação de Regras de Normalização** – até a **3ª Forma Normal**, eliminando redundâncias e garantindo integridade dos dados.

---

## 🧠 Objetivos

- Compreender a estrutura e organização de um banco de dados bem projetado
- Praticar a identificação de entidades, relacionamentos e atributos
- Aplicar corretamente as etapas da **normalização** (1FN → 2FN → 3FN)
- Criar bases consistentes e preparadas para consultas eficientes em SQL

---

## 📁 Estrutura dos Arquivos

Cada modelagem pode conter:

- `mer-diagrama.png` – Diagrama do MER criado no Visio
- `modelo-logico.txt` ou `.md` – Representação das tabelas e chaves
- `normalizacao.md` – Explicação das etapas de normalização

---

## 🛠️ Ferramentas Utilizadas

- Microsoft Visio (diagramas MER)
- Notação Entidade-Relacionamento tradicional (Chen)
- Documentação em Markdown para organização textual
