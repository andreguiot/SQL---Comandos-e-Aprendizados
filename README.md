# 🗃️ SQL – Comandos, Modelagens e Aprendizados

Este repositório reúne meus estudos e práticas com **SQL** e **modelagem de banco de dados**, com foco em consultas no **MySQL** e na construção de modelos conceituais utilizando o **modelo MER (Modelo Entidade-Relacionamento)** com o **Microsoft Visio**.

---

## 🎯 Objetivo

- Consolidar conhecimentos em **SQL**, com foco nos principais comandos:
  - `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`
  - `INNER JOIN` e outros tipos de junções
- Praticar **modelagem de dados** com base no modelo MER, organizando informações de forma lógica e estruturada
- Desenvolver e compartilhar **modelos relacionais simples**, aplicando-os em consultas práticas

---

## 🧠 O que você encontrará aqui

- 📜 Scripts SQL com comandos comentados
- 🧩 Exercícios práticos e resolvidos
- 🛠️ Modelagens de banco de dados em:
  - **Modelo conceitual (MER)** com diagramas feitos no **Microsoft Visio**
  - **Modelo lógico-relacional**, com tabelas normalizadas
- Exemplos de como transformar um MER em scripts SQL

---

## 💻 Ferramentas Utilizadas

- 💽 **MySQL** – Sistema Gerenciador de Banco de Dados
- 🧠 **Microsoft Visio** – Criação de diagramas MER (Modelo Entidade-Relacionamento)
- 📝 **MySQL Workbench** ou outro cliente SQL de sua preferência
